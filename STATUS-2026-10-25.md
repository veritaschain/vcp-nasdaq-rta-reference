# Status correction — 25 October 2026

This file corrects the current-tense status of this repository. It is a separate file because `README.md`, `verify.py`, `CHANGELOG.md` and the other pack files are listed in `hash_manifest.json`; editing them would break the manifest. Whether to annotate the README and regenerate the manifest is an owner decision. Statements in the hash-covered files predate this correction.

- This is a first-party conformance test dataset by VeritasChain Co., Ltd., which operates the VeritasChain Standards Organization (VSO). It targets VCP v1.1 (Platinum tier). VCP v1.1 has no tagged release and is superseded by VCP v1.2 (Released, tag `v1.2.0`).
- Conformance to any VCP tier, or to VAP, has not been independently established. "Platinum Tier compliance", "full VCP v1.1 Platinum Tier compliance" and "What This Package Proves" in the README are design targets, not results. There are zero external implementations of VAP or any of its profiles, including VCP.
- Not certified. VSO does not issue certifications itself. The certification scheme requires a Conformity Assessment Body (CAB) independent of the scheme owner; the only registered CAB, VeritasChain Co., Ltd., is not independent (VAP v1.2 ERRATA E-2026-10-21). Conformance is not compliance (VAP v1.2 §1.6); the SEC, FINRA, Reg NMS/CAT and EU AI Act sections of the README describe intended support, not compliance findings. The README's "Immutable hash chain architecture" should read "tamper-evident hash chain": the chain makes changes detectable, not impossible.

## Known limitations of this pack

- **No external anchor.** `anchors.json` has `external_tsa.status: "NOT_INCLUDED"` and an empty `Signature` (`{}`). The pack contains no RFC 3161 token or other external anchor proof, so it does not meet the external-anchoring requirement (VAP v1.2 INT-006; VCP Platinum). Nothing in the repository shows the "NDA production package" it refers to.
- **Third-party audit is a placeholder.** The README's "Independent verification by [Audit Partner]" names no auditor; no third-party attestation is included.
- **Signature checking in `verify.py` is optional.** `verify.py` checks event signatures only when PyNaCl is installed; without it, it prints "Skipped" and still reports `VERIFICATION PASSED`. It does not check the signatures in `certificates/`. (Checked on 2026-10-25 with a separate Ed25519 implementation: all 22 event signatures verify against `keys/signer_ed25519_pub.jwk`. This shows only that the signatures match the bundled key, not who holds it.)
- **Platinum anchor cadence not demonstrated.** Platinum requires anchoring every 10 minutes (VAP v1.2 §5.1.3). The pack has one anchor (2025-01-06T16:00:00Z) for one batch of 22 events timestamped from 09:30 to 16:05; a single anchor cannot show a 10-minute cadence.
- **Merkle construction.** `verify.py` duplicates the last node at odd-sized levels. It uses the RFC 6962 hash prefixes but not the RFC 6962 tree algorithm.
- **Check counts are inconsistent.** The README says "All 52 checks should pass"; `verifier_outputs/verification_report.txt` reports 48; running `verify.py` on 2026-10-25 without PyNaCl reported 42 (the signature checks were skipped).
- **Synthetic data.** `events.json` declares `"synthetic": true`.
- **Dates may be mis-stated (2025 vs 2026).** The pack is dated 2025-01-06 but cites VCP v1.1, which was published on 2025-12-30, and `hash_manifest.json` was generated on 2026-01-07 (the date the files were committed). The dates are not corrected because the files are hash-covered.
